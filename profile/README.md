# Prototir

Prototir is a platform for publishing, trying, and testing browser experiences and native builds.

Build for the browser with HTML, CSS, JavaScript, Three.js, Phaser, Construct 3, Unity, or Godot, or ship native Unity, Godot, and Unreal Engine builds for Windows, macOS, and Linux. Publish either format or both on one prototype page.

The SDKs connect real use to sessions, events, scores, and feedback. Every build gives testers **Feedback & tools** (Screenshot, Comment, Console and Performance) with no code from the creator. Native builds pair with the tester's account; browser builds also get persistent SDK storage and managed AI. The editors publish a build to Prototir in one step and tell creators when a newer SDK is out.
